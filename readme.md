# Shopping Cart
![image](https://github.com/user-attachments/assets/a0264799-e478-4371-a975-3736d304c2d2)

## 📑 Descrição
Projeto para simular um carrinho de compras.

## 🎯 Funcionalidades
- [X] : Adicionar, remover um, deletar todos e exibir itens no carrinho.
- [X] : Calcula o valor total.

## 💻 Tecnologias
- `Node.js`
- `Javascript`
- `HTML`
- `CSS`


## 🛠️ Como abrir e rodar o projeto

1. Run `node --watch src/index.js`
2. Run `node src/index.js`
